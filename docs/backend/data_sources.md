## 2. 기상 데이터

### 2-1. 기상청 단기예보 조회 서비스 ⭐ **MVP 필수**

**필요 이유**
- 현재 기온·습도 → 축종별 위험도(safe / caution / danger / emergency) 계산의 핵심 입력값
- 내일 최고·최저기온 예보 → 사전 경보 메시지 생성

| 항목 | 내용 |
|---|---|
| **API명** | 기상청_단기예보 조회서비스 |
| **publicDataPk** | `15084084` |
| **포털 URL** | https://www.data.go.kr/data/15084084/openapi.do |
| **베이스 URL** | `https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0` |
| **인증** | ServiceKey (쿼리 파라미터) |
| **비용** | 무료 (일 1,000회) |
| **응답 형식** | JSON / XML |

**오퍼레이션 목록**

| 오퍼레이션 | 설명 | 갱신 주기 | 사용 목적 |
|---|---|---|---|
| `getUltraSrtNcst` | 초단기실황 | 매시간 | 현재 기온·습도 실시간 파악 |
| `getUltraSrtFcst` | 초단기예보 | 30분 | 6시간 이내 기상 예측 |
| `getVilageFcst` | 단기예보 | 3시간 | 내일·모레 기온 예보 (경보 선발송용) |

**주요 응답 카테고리**

| 카테고리 | 설명 | 단위 |
|---|---|---|
| `T1H` | 기온 | °C |
| `REH` | 습도 | % |
| `WS` | 풍속 | m/s |
| `RN1` | 1시간 강수량 | mm |
| `SKY` | 하늘 상태 | 1(맑음) / 3(구름많음) / 4(흐림) |
| `PTY` | 강수형태 | 0(없음) / 1(비) / 3(눈) |

**요청 파라미터**

```
serviceKey  : API 키
base_date   : 기준 날짜 (YYYYMMDD)
base_time   : 기준 시간 (HHMM, 3시간 단위)
nx          : 기상청 격자 X (위도/경도 → 격자 변환 필요)
ny          : 기상청 격자 Y
numOfRows   : 조회 행 수
dataType    : JSON
```

**좌표 변환**: 위도/경도(WGS84) → 기상청 격자(LCC 투영) 변환 필요
- 구현 위치: `app/data/kma_client.py` → `LatLngToGrid.dfs_xy_conv()`

**신청 방법**
```
1. data.go.kr 로그인
2. 위 포털 URL 접속 → [활용신청]
3. 용도: "개인 프로젝트" → 즉시 자동 승인
4. 마이페이지 → API 관리 → 인증키 복사 → .env KMA_API_KEY 설정
```

**필요 이유**
- 기상청이 **폭염 특보·한파 특보**를 발령하면 위험도를 자동으로 `emergency`로 상향
- 광역 경보를 농가 단위 알림으로 변환

| 항목 | 내용 |
|---|---|
| **API명** | 기상청_특보 조회서비스 |
| **publicDataPk** | `15139476` |
| **포털 URL** | https://www.data.go.kr/data/15139476/openapi.do |
| **인증** | ServiceKey |
| **비용** | 무료 |

**주요 특보 종류**

| 특보 | 조건 | 위험도 처리 |
|---|---|---|
| 폭염 주의보 | 최고기온 33°C 이상, 2일 이상 | caution 이상 강제 |
| 폭염 경보 | 최고기온 35°C 이상, 2일 이상 | danger 이상 강제 |
| 한파 주의보 | 최저기온 −12°C 이하 등 | caution 이상 강제 (소·한우) |
| 한파 경보 | 최저기온 −15°C 이하 등 | danger 이상 강제 |

**신청 방법**: 단기예보 API와 동일 (포털 URL만 다름)

## 5. 지도 및 위치 데이터

### 5-1. Kakao Map API ⭐ **MVP 필수**

**필요 이유**
- 피해 농가 위치를 **지도 위에 위험도별 마커**로 시각화 (기부 웹 핵심 화면)
- 역지오코딩(위도/경도 → 주소 변환): 농가 등록 시 주소 자동 표시
- 백엔드에서 위도/경도만 저장하고, 주소 표시는 REST API로 처리

| 항목 | 내용 |
|---|---|
| **서비스** | Kakao Map API |
| **URL** | https://developers.kakao.com |
| **비용** | 무료 (지도 월 300만 건, 역지오코딩 일 10만 건) |
| **인증** | JavaScript 키 (웹), REST API 키 (백엔드) |
| **역지오코딩** | ✅ REST API 지원 (`/v2/local/geo/coord2address.json`) |

**사용 분야**

| 용도 | 키 종류 | 구현 위치 |
|---|---|---|
| 지도 렌더링 (웹) | JavaScript 키 | `packages/web` |
| 역지오코딩 (백엔드) | REST API 키 | `packages/backend/app/api/farms.py` |

**역지오코딩 엔드포인트**
```
GET https://dapi.kakao.com/v2/local/geo/coord2address.json
    ?x={경도}&y={위도}&input_coord=WGS84
Authorization: KakaoAK {REST_API_KEY}
```

**신청 방법**
```
1. developers.kakao.com → 로그인
2. [내 애플리케이션] → 새 앱 생성 → "Give On"
3. Web 플랫폼: 사이트 도메인 등록 (http://localhost:3000 포함)
4. 앱 키 탭에서 JavaScript 키, REST API 키 복사
5. .env에 설정:
   KAKAO_REST_API_KEY=...
   NEXT_PUBLIC_KAKAO_MAP_API_KEY=...
```

## 📎 찾는 방법 (유사 API 탐색)

공공데이터포털에서 추가 API를 찾을 때:

```
1. data.go.kr 검색창에서 키워드 검색:
   - "기상" → 기관: 기상청 필터
   - "축산" → 기관: 농림축산식품부, 축산물품질평가원 필터
   - "농업기상" → 기관: 농촌진흥청 필터

2. 전문 포털 직접 탐색:
   - data.kma.go.kr (기상자료개방포털) → 응용기상 > 생활기상지수
   - data.mafra.go.kr (농림축산식품 공공데이터 포털)
   - naas.go.kr (국립농업과학원)

3. API 타입 필터:
   - "오픈 API" 선택 → REST/JSON 형태만 노출
```
